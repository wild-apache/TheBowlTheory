# The Bowl Theory

Production landing site for The Bowl Theory.

## Run
Serve this directory with any static web server. No build step is required.

## Configuration
Update `CONFIG` in `script.js` for `SWIGGY_URL`, `ZOMATO_URL`, `INSTAGRAM_URL`, and `CONTACT_URL` when real URLs are available. Menu data is the `MENU` array in the same file.

Official brand SVGs live under `assets/logo/` and are sourced from The Bowl Theory Logo Master Pack v3.1.
